Serial Monitor

macOS 原生串口调试助手 · UI 设计规范（基于 Apple Human Interface Guidelines）

定位 这是独立于功能需求文档的界面设计基线。它定义产品应该“长什么样、如何组织、状态如何表达、菜单怎样工作”，用于 SwiftUI 页面开发和验收。
依据 本规范以 Apple 官方 Human Interface Guidelines（developer.apple.com/design/human-interface-guidelines，2026 版）为准，重点参考 Layout、Toolbars、Buttons、Typography、Segmented Controls、Pop-up Buttons、Windows。HIG 对间距/圆角多为原则性描述，本文将其落为具体令牌（标注“推导值”）。

1. 设计目标与原则

原生而克制

优先系统控件、窗口习惯与 macOS 菜单，不做网页后台式大色块或复杂装饰。

信息密度可控

接收区为主视觉，配置与预设可收起；高频信息一眼能定位，低频项不干扰调试。

状态优先

连接、日志、自动发送、错误都用文字、图标和颜色三重表达，不能只靠颜色。

读码第一

玻璃材质只作为层级与容器，不侵入长日志阅读区域；控制台始终保持清晰对比度。

  • 采用“专业工具 + Apple 原生”气质，参考 Console、Xcode 检查器与系统设置的阅读节奏。
  • 默认浅色、跟随系统外观；用户可在设置中指定浅色、深色或跟随系统。
  • 默认窗口最小尺寸为 980 × 680 pt；窗口变窄时先收起检查器，再压缩次要文本，最后才允许横向表格滚动。
  • Liquid Glass / Material 仅用于工具栏、浮层、侧栏和短操作块；数据控制台使用实色或高不透明材质。
  • 布局遵循 8 pt 栅格与 20 pt 窗口内容边距；自定义控件圆角与所在栏同心（Apple HIG）。

5. 组件与状态

5.1 状态表达

状态视觉主按钮用户可操作项
未连接中性灰状态徽标打开串口可编辑所有参数、发送区禁用、预设单发禁用。
连接中橙色进度指示 + “正在打开…”取消锁定端口与参数；保留刷新但不触发连接切换。
已连接绿色徽标 + 当前端口关闭串口启用发送、自动发送、日志和预设循环。
暂停显示控制台顶端橙色细条恢复显示串口、日志与后台收包继续运行；仅暂停渲染自动滚动。
连接错误红色徽标 + 可复制错误摘要重新连接停止所有自动发送；允许修改参数、刷新端口和查看详细错误。

5.2 核心组件规则

端口选择器

显示友好名优先、完整路径次级显示；缺失端口保留为灰色“上次使用的端口不可用”。

主操作按钮

每个区域最多一个蓝色强调按钮。危险操作不用蓝色，使用确认弹窗或红色文字按钮。

记录行

方向用 RX/TX 标签 + 语义色；不为每行添加强背景。鼠标悬停只显示轻微底色和复制图标。

输入校验

HEX 错误在输入框下方就近说明，指出奇数字符或非法字节；不弹出打断式警告。

7. 快捷键规范

动作快捷键条件与冲突处理
新建会话⌘N始终可用；V1.0 重置当前会话工作区，若有运行日志或未保存编辑则提示。
打开 / 关闭串口⌘O / ⌘W根据状态只启用其一；不得覆盖系统关闭窗口的标准预期，必要时关闭窗口使用 ⌘⇧W。
发送当前数据⌘↩已连接、输入合法、TX 队列未被独占时可用；普通 Return 保留给多行换行。
自动发送⌘⇧↩自动发送与预设循环互斥；启动前静默停止另一模式并在状态栏说明。
开始 / 停止日志⌘L仅已连接时开始可用；停止记录始终可用。
清空接收记录⌘K仅清内存视图；不影响日志，初次操作显示轻提示。
设置⌘,使用 macOS 标准快捷键。

8. 交互规则

  1. 自动滚动：新记录到来时仅在用户停留在底部附近才自动跟随；手动上滚后显示悬浮“回到最新数据”按钮，不强制抢占阅读位置。
  2. 暂停显示：暂停按钮切换为“恢复显示”，同时在控制台顶部出现常驻状态条；后台仍完成记录、缓存和日志写入。
  3. 模式切换：接收 ASCII/HEX 仅改变渲染；发送模式改变当前输入的解释方式。切换为 HEX 时立即校验，不清空用户文本。
  4. 保存：设置采用即时保存；预设编辑 Sheet 采用显式“保存”。关闭时只有未保存预设编辑、日志仍在记录或正在连接才要求确认。
  5. 危险操作：删除预设、恢复默认设置采用确认对话框；清空接收记录允许撤销提示但不二次确认，避免高频操作负担。
  6. 反馈优先级：输入框内校验 → 局部提示 → 状态栏 → Alert。只有会中断会话、造成数据丢失或需要用户选择的情况才弹 Alert。

9. 可访问性与窗口适配

主题要求
VoiceOver状态徽标朗读“串口状态：已连接，/dev/cu.usbserial，115200 波特率”；图标按钮必须有明确 accessibilityLabel。
键盘操作工具栏、控制台操作、发送区、预设列表、设置表单可按逻辑顺序 Tab 聚焦；预设排序提供键盘替代操作。
颜色对比正文与背景达到可读对比；RX/TX/错误除颜色外必须有文字标签、图标或方向列。
减少动态效果检测 Reduce Motion 后取消连续呼吸、材质变形与非必要滚动动画，保留瞬时状态变化。
窄窗口优先隐藏预设检查器，控制台和发送区保留；工具栏参数压缩为摘要 + Popover，不让控件断行堆叠。

10. SwiftUI 实施映射

设计面SwiftUI 结构少量 AppKit 补充
应用与菜单App、WindowGroup、Commands、Settings必要的菜单验证与窗口控制。
主工作区NavigationSplitView 或 HSplitView；Toolbar；InspectorNSSplitView 细节仅在 SwiftUI 无法满足时桥接。
控制台ScrollView + LazyVStack，或高性能文本视图封装大量长文本、选择复制、虚拟化可采用 NSTextView 的 NSViewRepresentable。
配置与编辑Form、Picker、TextField、TextEditor、Sheet、PopoverNSAlert 用于系统风格的破坏性确认和错误处理。
视觉材质Material、controlSize、tint、symbolRenderingMode系统版本可用时采用 Glass API；低版本回退 Material。
设计令牌DesignTokens：contentInset=20、controlCornerRadius=6、containerCornerRadius=10、间距 4/8/16/20；AppFontRole 按 HIG 字号（17/15/13/13/12/11/10）玻璃封装见 VisualEffectsSupport；标题栏装饰图标用 NSTitlebarAccessoryViewController。
最终验收重点 任何一个界面状态下，用户都应该能在 1 秒内知道：当前是否已连接、正在看什么格式、自动发送是否运行、日志是否记录，以及下一步能点击什么。若需要阅读大量说明才能判断状态，UI 即不合格。
