# P3 · 自动发送、预设、日志与设置

## 目标、前置与文件所有权

完成 Beta：自动发送和预设循环、预设与会话草稿持久化、JSONL 日志、设置、菜单及快捷键。前置条件是 P1/P2 的统一接口已稳定；本阶段只能在 02 拥有的 `SessionCoordinator` 中做明确的接线扩展。

本阶段创建 `Application/{SendScheduler,LogService,SettingsService,Presets}/**`、`Infrastructure/Persistence/**`、`Features/{Presets,Settings,Logging}/**`、`App/Commands/**` 及对应测试。唯一允许修改既有文件为 `SessionCoordinator.swift`、`SessionViewModel.swift`、`StatusBarView.swift` 与 `SerialMonitorApp.swift`，且只用于下述接线。

## 冻结行为

- `SendScheduler` 是 actor，由 SessionCoordinator 唯一持有；普通自动发送和预设循环互斥，单一循环 task 必须 await 前一次发送完成后再按单调时钟等待。
- 自动发送每 tick 读取当前编辑器快照；参数/编码/行结束符改变、断开、错误或退出立即停止并发布原因。预设循环每轮读取已保存、按 `sortOrder` 排序的启用预设快照。
- `LogService` 是 actor，提供 start、append、stop、flushAndClose 和 status updates；写失败只把日志转 failed，不中断会话。日志为 UTF-8 JSONL，含时间、方向、format、易读 data、Base64 原始字节、来源和可选预设快照。
- `PresetService` 和 `SettingsService` 通过独立 AsyncStream 广播；JSON 文件带 `schemaVersion`，原子写入，损坏文件备份后回退安全默认值。自动发送草稿可恢复，运行态绝不自动恢复。

## 实现顺序

1. 先创建预设、调度、日志和设置的值模型与纯校验；完成 JSONL 编码、文件命名、轮转、路径清洗和持久化单测。
2. 实现 SendScheduler，并由 SessionCoordinator 的既有 TX 入口注入发送 handler；关闭、error 和退出路径统一停止调度。
3. 实现 PresetService、预设检查器和编辑 Sheet；支持 CRUD、启用、排序、单发、循环、快照语义和两段删除。
4. 实现 LogService、状态栏日志控件、目录选择 security-scoped bookmark 和崩溃标记；连接自动日志与手动开始/停止均经协调器裁决。
5. 实现 SettingsService、设置窗口和 Commands；设置即时影响显示/缓存，日志设置只影响新日志会话，菜单可用性从 ViewModel 的单一状态投影计算。

## 验证与完成条件

- 虚拟时钟测试覆盖调度互斥、无重入、取消、间隔边界与停止原因。
- 临时目录测试覆盖预设/设置恢复、损坏回退、JSONL Base64 往返、轮转、日志失败隔离和退出 flush。
- 集成测试覆盖预设来源快照、断开停止调度、日志不中断 RX/TX、设置即时生效不丢数据。
- 运行 `xcodebuild test -scheme SerialMonitor`；XCUITest 覆盖预设 CRUD/循环、日志状态、设置校验、主要菜单和快捷键。所有测试全绿后标记 Beta。
