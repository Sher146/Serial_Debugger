# P2 · 主工作区 UI

## 目标、前置与文件所有权

依据需求文档和 `设计图/` 落地原生 SwiftUI 单窗口：连接工具栏、接收控制台、发送编辑器、可收起预设占位区和状态栏。前置条件是 P1 已交付的 `SessionClient`；本阶段使用其 mock 进行 Preview 与测试。

本阶段创建 `SerialMonitor/Features/Session/**`、`SerialMonitor/Shared/{DesignTokens,Localization,Accessibility}/**`、Assets、主工作区 UI tests。不得修改 Domain 或 Application 接口，不实现预设、真实日志、设置或菜单命令。

## 冻结 UI 消费方式

`SessionViewModel` 是 `@MainActor`，只持有 `any SessionClient`，并只从 `SessionEvent` 更新端口、状态、记录、计数、日志状态和错误。它不得直接持有 `SerialPorting`、`FileHandle` 或日志服务。

显示格式是 ViewModel 偏好：HEX 从 `rawBytes` 投影，ASCII 使用 Domain 解码器；暂停只冻结可见记录和自动滚动，事件仍继续进入缓存与统计。发送文本先经 `SendPayloadEncoder` 生成 `SendRequest`，失败保留输入并显示定位错误。

## 实现顺序

1. 建立 String Catalog、语义色、字体、间距和可访问性令牌；深浅色均使用系统语义色/Material，控制台维持可读对比度。
2. 实现可 mock 的 SessionViewModel、四态 Preview、批量事件消费、暂停/恢复、格式切换和计数投影。
3. 实现连接工具栏：端口刷新、参数编辑、opening/closing 锁定、状态三重表达和连接/取消/断开动作。
4. 实现控制台与发送区：时间戳、RX/TX、尾随、回到底部按钮、HEX 错误提示、⌘Return 发送、未连接禁用。
5. 实现状态栏和预设占位容器；窗口最小尺寸固定为 980×680 pt。

## 验证与完成条件

- Preview 覆盖 disconnected/opening/connected/error；深浅色和 Reduce Motion 下无连续动画或布局溢出。
- ViewModel 单测覆盖事件投影、暂停不丢记录、HEX 基于 UTF-8 原始字节、连接参数锁定和发送禁用态。
- XCUITest 覆盖启动、连接按钮状态、HEX 拦截、暂停横幅、格式切换、最小窗口和核心 accessibility label。
- `xcodebuild test -scheme SerialMonitor` 全绿，115200 bps mock 流下 UI 不阻塞。
